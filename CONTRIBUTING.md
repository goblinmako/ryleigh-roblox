# How to Work on This Game 🎮

Hey Ryleigh! Here's how to open the project in **Roblox Studio** using a tool called **Rojo**.
Rojo keeps your scripts saved as real files so GitHub can track every change.

---

## What you need first

1. **Roblox Studio** — already installed if you've been building games.
2. **Rojo** (the plugin + the app) — follow the two steps below.

---

## Step 1 — Install the Rojo plugin in Studio

1. Open **Roblox Studio**.
2. Go to the **Toolbox** → search **Rojo**.
3. Click the plugin by **Roblox** (or **Uplift Games**) and hit **Install**.
4. You'll see a small **Rojo** button appear in your Studio toolbar.

---

## Step 2 — Install the Rojo app on your computer

1. Go to [https://rojo.space](https://rojo.space) and download the latest version for your computer.
2. Unzip it and put the `rojo` file somewhere easy (like your Desktop or Documents).

---

## Step 3 — Open the project

1. Download or clone this repo to your computer (ask for help if you need it).
2. Open a **Terminal** (or Command Prompt) and go to the repo folder:
   ```
   cd path/to/ryleigh-roblox
   ```
3. Start Rojo:
   ```
   rojo serve
   ```
4. In **Roblox Studio**, click the **Rojo** button in the toolbar → **Connect**.
5. Your scripts will now sync automatically — save a script in Studio and it updates the file, save the file and it updates Studio. 

---

## Step 4 — Save your work to GitHub

Whenever you finish working, commit your changes:

1. Go to the repo on GitHub.
2. Upload any changed files, or if you're using Git on your computer, just run:
   ```
   git add .
   git commit -m "what I built today"
   git push
   ```

---

Not sure about any of these steps? Just ask — we'll walk through it together! 🚀
